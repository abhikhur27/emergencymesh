# Temoc's offline model

The full Mac handoff includes `qwen2.5-1.5b-instruct-q4_k_m.gguf` here. Model weights are deliberately excluded from Git.

The source-only app builds without the weights and offers an explicit model download or file import. Once installed, chat inference has no network dependency. See `docs/TEMOC.md` for the pinned official model, checksum, license and device verification limits.
