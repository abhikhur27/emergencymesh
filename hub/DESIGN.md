# Operator console direction

This is an incident desk for a local hackathon demonstration. Its primary task is to inspect an original request, confirm a human review and export a clearly simulated handoff. Trust requires visible link state, source fields and honest acknowledgment semantics.

Direction: light security operations console. White paper and muted gray-green workspace, ink text, forest green actions, red/amber only for user-reported priority. System sans is deliberate for an offline native-feeling utility; monospace is reserved for IDs, coordinates and file paths. Type scale11/12/13/15/20/22/30/36;8px spacing rhythm;4px radius only on inputs/buttons; no ornamental shadows or animations.

Layout: compact connection strip, left incident queue and right source/receipt detail. Small screens stack queue then detail. Original report precedes optional AI extraction. Every control is a real button/input/select, focused with a visible ring,44px minimum action heights, color supplemented with text, no decorative motion and no remote fonts/maps.

Source review against anti-ai-slop-ui: no marketing hero/card grid, gradients, emoji icons, artificial metrics, glow or fake activity. Self-assessed AI Slop Score2/10, distinctiveness7/10: hierarchy comes from the incident workflow, thin rule structure and exact source/receipt trail. These are design judgments, not a rendered accessibility certification. Parent integration owns actual browser captures and interaction evidence.
